# 团队偏好学习指南

> 何时读：需要了解偏好学习机制的设计思路时。
> **状态**：设计文档，尚未实现。当前版本通过 `.optimizer_history/` 记录修复历史，偏好学习是未来方向。

---

## 设计思路

每次用户修改了 skill 后，记录修改模式到 `.optimizer_history/preferences.json`。下次优化时参考这些偏好。

## 记录的修改模式

| 模式类型 | 记录内容 | 用途 |
|---|---|---|
| 格式偏好 | 用户喜欢的 reference 格式（表格/列表/段落） | 下次生成 reference 时自动适配 |
| 长度偏好 | 用户对 SKILL.md 行数的容忍度 | 调整拆分阈值 |
| checklist 风格 | 用户喜欢的 checklist 格式（简短/详细） | 下次生成 checklist 时自动适配 |

## 记录格式

```json
{
  "format_preferences": {
    "reference_style": "表格",
    "checklist_style": "简短"
  },
  "threshold_preferences": {
    "max_skill_md_lines": 180,
    "min_score": 85
  },
  "modification_history": [
    {
      "timestamp": "2025-06-01T10:00:00",
      "file": "references/xxx.md",
      "change": "从段落格式改为表格格式"
    }
  ]
}
```

## 实现路线

1. **当前**：`fix_skill.py` 记录修复历史到 `.optimizer_history/`
2. **下一步**：统计修改频率，自动识别偏好
3. **未来**：用 LLM 分析修改原因，提取更深层的偏好
