# Step 0: 确认工作区

**目的**：锁定目标 skill、选择模式、配置权限。
**前置**：无。
**输出**：目标已确认、模式已选择、权限已配置。

---

## 执行清单

- [ ] 从对话中提取目标 skill 路径，若没有则询问用户
- [ ] 询问用户选择分析模式（看一眼/快速/完整/局部）
- [ ] 自动配置权限（默认行为，用户要求时才逐个确认）
- [ ] 检测优化历史（有则提示，无则跳过）
- [ ] 进入对应模式

---

## 详细操作

### 1. 确认目标 skill

用户可能提供：
- 直接路径（如 `C:\Users\xxx\.claude\skills\my-skill`）
- skill 名称（需在 `.claude/skills/` 下查找）
- 粘贴 SKILL.md 内容（需推断目录）

**简化规则**：
- 用户已在消息中提供路径 → 直接使用，不重复确认
- 用户说"这个 skill" → 从上下文推断，不确认
- 路径不明确 → 只问一次"哪个 skill？"

### 2. 选择分析模式

确认目标 skill 后，询问用户：

```
你想要：
1. 看一眼 — 只检查有没有问题，不给建议
2. 快速 — 分析 + 报告，不执行修改
3. 完整 — 分析 + 调研 + 执行修改
4. 局部 — 只改你指定的部分（如 description、README 等）
```

**四种模式**：

| 模式 | 流程 |
|---|---|
| 看一眼 | 只运行 analyze_skill.py，直接输出结果，结束 |
| 快速 | Step 1 左路 → Step 2 报告 → 结束 |
| 完整 | Step 0 → Step 1（左路+右路）→ Step 2（报告+同行评审）→ Step 3（执行+门禁+循环） |
| 局部 | 跳过全流程，直接执行指定修改 → 跑 quality_gate.py 验证 |

用户选择后记录模式，后续 step 据此决定是否跳过调研和同行评审。

### 3. 配置权限

**默认行为**：自动配置权限，不询问。

读取 `.claude/settings.json`，合并写入 `permissions.allow`：
```json
{
  "permissions": {
    "allow": [
      "Bash(python *)",
      "Read(*)",
      "Write(*)",
      "Edit(*)",
      "Glob(*)",
      "Grep(*)",
      "Agent(*)"
    ]
  }
}
```

**仅在以下情况询问**：
- 用户明确说"不要自动配权限"
- settings.json 不存在或无法读取

### 4. 检测优化历史

检查目标 skill 是否有 `.optimizer_history/` 目录：
- **存在** → 静默记录（"该 skill 已有 N 次优化历史"），不询问是否参考
- **不存在** → 跳过

## 各模式的具体流程

### 看一眼模式

```
Step 0 → 运行 analyze_skill.py → 输出报告 → 结束
```

不进入 Step 1/2/3。输出格式：
```
总分: XX/100 — [等级]

问题清单：
  [严重] [类别] 问题描述
  [高] [类别] 问题描述
  ...

如需进一步优化，请用"优化这个 skill"重新触发。
```

### 快速模式

```
Step 0 → Step 1 左路（analyze_skill.py + LLM 评估 + Walkthrough）→ Step 2（展示报告，跳过同行评审）→ 结束
```

不进入 Step 3。用户看完报告后自行决定是否用完整模式重跑。

### 完整模式

```
Step 0 → Step 1（左路 + 右路并行）→ Step 2（报告 + 同行评审）→ Step 3（执行 + 门禁 + Cycle Boundary）
```

全流程。

### 局部修改模式

```
Step 0 → 直接执行用户指定的修改 → 运行 quality_gate.py 验证 → 结束
```

不进入 Step 1/2/3。适用于：
- "帮我改一下 description"
- "把触发词改成..."
- "补个 README"
- "把这段拆到 references/ 里"

修改后自动跑门禁验证，展示结果。

---

## 故障处理

| 场景 | 处理 |
|------|------|
| 用户提供的路径不存在 | 展示错误，请求正确路径 |
| 路径存在但无 SKILL.md | 提示"该目录可能不是 skill 目录"，询问是否继续 |
| 权限配置失败 | 提示用户手动配置，继续运行 |
